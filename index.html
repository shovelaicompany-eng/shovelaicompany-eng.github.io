ShovelAI Channel Manager

ShovelAI Channel Manager is a private internal tool operated by ShovelAI LLC, a California single-member limited liability company.

The app is used only by ShovelAI LLC to manage the company's own YouTube channel, The Collector's Chair (@collectorschair), a fragrance channel. It uses the YouTube Data API to read channel statistics and to edit video metadata and uploads for that channel.

This application is not offered to the public and has no third-party users.
